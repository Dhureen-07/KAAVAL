## Project Overview
KAAVAL AI is an advanced public‑safety and emergency intelligence platform built for law‑enforcement officers. It combines OCR, language translation, a Retrieval‑Augmented Generation (RAG) assistant, and automated FIR drafting, all wrapped in a glassmorphic Next.js UI.

## Technology Stack
- **Frontend**: Next.js 16 (App Router) with TypeScript, Tailwind CSS, PostCSS, shadcn‑ui / Radix components, and custom React hooks.
- **Backend**: Python 3 (standard library HTTP server) exposing REST endpoints, SQLite (`kaaval.db`) for persistent storage, FastAPI listed in `requirements.txt` (available for optional async API), Hugging Face models (TrOCR, NLLB‑200) and OpenRouter LLMs for reasoning.
- **AI/ML**: Hugging Face inference APIs, OpenRouter commercial models, local simulation fallback when API keys are missing.
- **Database**: SQLite accessed via `backend/database.py`.
- **DevOps**: npm scripts (`dev`, `build`, `start`, `lint`); Python virtual environment recommended.

## Build & Run Instructions
### Backend (Python)
1. `cd backend`
2. *(optional)* `python -m venv venv && source venv/bin/activate`
3. `pip install -r requirements.txt`
4. Ensure a `.env` with `HF_TOKEN` and `OPENROUTER_API_KEY` (see README) or run in simulation mode.
5. `python main.py` – starts the HTTP server on port 8000.

### Frontend (Next.js)
1. From project root: `npm install`
2. Development: `npm run dev` (http://localhost:3000)
3. Production build: `npm run build && npm start`
4. Linting: `npm run lint`

## Code Style Guidelines
- **Frontend**: ESLint with `eslint-config-next`; TypeScript `strict` mode enabled; follow existing component patterns (shadcn‑ui conventions, Tailwind utility classes). No `any` unless necessary.
- **Backend**: PEP 8, type hints where used, `pydantic` for data validation, and `python-dotenv` for env handling. Keep functions small and single‑purpose; avoid long monolithic handlers.

## Security Considerations
- API keys (`HF_TOKEN`, `OPENROUTER_API_KEY`) are read from `backend/.env`. Do **not** commit this file; it is excluded by `.gitignore`.
- The server runs without authentication; in production, wrap it with a gateway or add auth checks.
- Simulation mode ensures the service continues operating when credentials are missing, avoiding accidental credential exposure.
- SQLite file `kaaval.db` may contain sensitive case data – protect it with OS permissions and consider encryption for production.

## Deployment Notes

- Backend can be containerised (Docker) or run as a systemd service. Ensure environment variables are supplied securely.
- Update `next.config.ts` if custom rewrites or environment variables are needed.
